**Building now: Quietkey.** AI coding agents like Claude Code and Codex keep a full transcript of every session on your disk: every command they ran, every file they read. Any API key that passes through ends up in there in plain text, often dozens of times. When I scanned my own Mac I found 236 of them. Most were never pasted by me; the agent read a `.env` or ran a command and saved what it saw.

Quietkey is a calm, open-source macOS app and CLI that finds those secrets, shows how each one got there, and cleans up the safe parts for you. Nothing leaves your Mac. Coming soon; follow along on X.
